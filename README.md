# Своя игра

Викторина в стиле «Своей игры» с кнопками на телефонах. Ведущий открывает сайт на ноутбуке или ТВ,
игроки заходят по коду комнаты или QR-коду со своих телефонов — без установки приложений.

**Возможности:** классическая игра с кнопкой и режим викторины с вариантами, игра с ведущим и без него,
кот в мешке, аукцион, финал со ставками, импорт паков SIGame (.siq), Excel, Word и текста,
редактор паков, картинки на экране и телефонах, приватные и открытые комнаты,
заставка «тема и стоимость» перед вопросом, отдельный экран для зрителей,
финальный экран с пьедесталом и номинациями.

**Большой экран для зрителей:** откройте на телевизоре или проекторе ссылку из лобби
(«Ссылка для экрана», вида `…?screen=1234`) или «Большой экран» на главной.
Там видны табло, вопросы и очки, но нет правильных ответов и кнопок ведущего.

## Как устроен код
- `index.html` — разметка-шаблон страницы.
- `src/styles.css` — все стили.
- `src/js/01-firebase.js … 20-boot.js` — разделы скрипта по порядку номеров.
- Vite склеивает всё это в один файл `dist/index.html` — его и получают игроки.

Для связи между устройствами нужен проект Firebase Realtime Database; его настройки —
в `src/js/01-firebase.js`.

## Команды
```
npm install      # один раз
npm run dev      # локальный сайт для разработки, обновляется при правках
npm test         # собрать dist/ и прогнать сценарии на собранной версии
npm run build    # только собрать dist/
```

## Публикация
При каждом пуше в `main` GitHub Actions (`.github/workflows/deploy.yml`) собирает сайт,
запускает тесты и, если всё прошло, публикует `dist/` на GitHub Pages.
